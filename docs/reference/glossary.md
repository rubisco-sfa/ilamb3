# Glossary
A glossary of terms used in `ilamb3` is provided below. This is not an exhaustive list, but it should help clarify some of the terminology used in the documentation and code.

:::{glossary}
reference
: Refers to a dataset which will be considered as the source of truth in the given comparison. Many times this is some kind of observational dataset, but can be any dataset of your choosing. Errors and scores will be calculated with respect to this dataset.

comparison
: Refers to the dataset being compared to the reference dataset. Usually, this is a model output dataset, but could be any dataset of your choosing.

scalar
: A scalar is a single numerical value that is generated by an analysis function. In `ilamb3` it can be a scalar metric such as mean absolute error, or other single numerical values such as the mean over a region and the time period.

score
: A monotonic function that maps an error to a value from 0 to 1, where 1 is perfect. The error measures the difference between the comparison and the reference and is 0 when they match. The score is a nonincreasing function of the error, so a smaller error never receives a lower score. See [Scoring](../deep-dive/scoring.md).

local score
: A score computed from the error in a single cell, such as one pixel of a score map. Local scores are valid as maps but must not be averaged into a regional score; `ilamb3` refuses to aggregate them. See [Scoring](../deep-dive/scoring.md#local-scores).
:::
